O que é o Sellbird?

O Sellbird é uma plataforma de prospecção de código aberto. Depois de configurado, ele roda sozinho: encontra pessoas que encaixam no seu cliente ideal, escreve e-mails frios personalizados (em português para empresas do Brasil, em inglês para as de fora), envia pela sua plataforma de e-mail, lê todas as respostas, lida com objeções e trabalha para marcar uma reunião. Você revisa tudo por este painel.

O Sellbird roda na sua assinatura do Claude Max (ou, se você escolher, no seu plano do ChatGPT pelo Codex), então não há custos extras de IA. Tudo fica no seu computador, numa pasta só.

Primeiros passos

São três coisas para fazer:

1. Vá na aba Configurações e conecte um provedor de e-mail (Gmail recomendado) 2. Treine o Sellbird no seu produto (pelo Claude ou pela linha de comando) 3. Vá na aba Controles e clique em Ligar

A aba Hoje mostra exatamente o que já foi feito e o que ainda falta.

Onde fica cada coisa

Tudo de que o Sellbird precisa está dentro desta pasta do projeto. Nada fica guardado em outro lugar.

.envSuas chaves de API e credenciais (nunca compartilhadas nem enviadas ao git)
sellbird.yamlAs informações do seu produto, clientes-alvo e configurações de comportamento
skills/Arquivos de conhecimento de vendas. Edite para mudar como o Sellbird escreve e vende.
skills/product_knowledge.mdTudo o que o Sellbird sabe sobre o seu produto (gerado no treinamento)
prompts/Modelos de prompt de cada agente. Personalização avançada.
data/sellbird.dbBanco de dados com todos os prospects, campanhas e conversas
data/sellbird.logArquivo de registro mostrando o que o Sellbird está fazendo

Pegando suas chaves de API

Chave de API do Instantly (antigo)

O Instantly é a opção de envio antiga; Gmail ou SMTP são os recomendados.

1. Cadastre-se em instantly.ai (você precisa do plano Growth para ter acesso à API)

2. Vá em Settings > Integrations

3. Copie sua chave de API

4. Cole na aba Configurações aqui

Credenciais do LinkedIn (opcional)

Se você quer que o Sellbird encontre prospects no LinkedIn, informe seu e-mail e senha do LinkedIn. O Sellbird usa um navegador de verdade para pesquisar como uma pessoa faria, com pausas aleatórias e limites de uso.

Se você pular isto, o Sellbird encontra prospects por buscas no Google e lendo os sites das empresas.

Cloudflare Browser Rendering (opcional)

Só é usado no treinamento do produto (quando o Sellbird lê o seu site para aprender sobre o produto). Ele lida com sites cheios de JavaScript que um leitor simples não consegue ler.

1. Cadastre-se em Cloudflare (plano Workers pago, ~US$ 5/mês)

2. Vá em Workers & Pages > Browser Rendering

3. Crie um token de API com permissão de edição no Browser Rendering

4. Informe seu ID da conta e o token de API na aba Configurações

Sem isso, o Sellbird usa um leitor próprio que funciona bem na maioria dos sites, mas não roda JavaScript.

Problemas comuns

"command not found: sellbird" (comando não encontrado)
Você precisa ativar o ambiente virtual primeiro: source .venv/bin/activate
A API do Instantly devolve 401
Sua chave de API está errada ou você precisa do plano Growth (o plano grátis não inclui API). Confira a chave em Settings > Integrations no painel do Instantly.
O modo sem interface do Claude falha
Confira se você rodou claude login no terminal e tem uma assinatura Claude Max ativa. O Sellbird usa a assinatura que você já tem, não uma chave de API separada.
As chamadas ao Codex falham
Com brain.provider: codex, defina brain.model como um ID de modelo disponível, incluindo Luna, Sol ou Terra (por exemplo gpt-6.1-sol), ou deixe em branco para escolher um modelo da lista. O Sellbird roda esses modelos sem ferramentas; gpt-5.5 também continua aceito quando está no catálogo da sua conta. Rode codex login e escolha "Sign in with ChatGPT" (login por chave de API é recusado). O Sellbird nunca renova seu login do Codex: se o registro disser que expirou ou precisa renovar, use o Codex uma vez ou rode codex login. O Sellbird precisa do Codex CLI 0.159.3 no macOS ou Linux (o Codex não funciona no Windows; use o Claude lá) e recusa outras versões. Enquanto o Codex não puder ser usado, o Sellbird pausa (a aba Hoje mostra "Codex pausado" e o motivo), não mexe nas respostas e e-mails na fila, e volta quando for resolvido; sellbird status --check confere na hora. Se o registro disser que o isolamento não pôde ser verificado, alguma configuração do Codex está forçando uma ferramenta, hook, servidor MCP ou endereço próprio de volta; o Sellbird se recusa a mandar prompts até isso ser removido. O Sellbird nunca volta para o Claude sozinho.
O Sellbird não está encontrando prospects
Confira se o seu ICP (perfil de cliente ideal) no sellbird.yaml tem cargos, segmentos e regiões realistas. Para a busca grátis no Brasil, use segmentos como "clínica odontológica", "contabilidade" ou "imobiliária" e cidades como "Curitiba, PR". Se o LinkedIn estiver configurado, confira as credenciais. Veja a aba Atividade para saber o que o Sellbird tentou fazer.
